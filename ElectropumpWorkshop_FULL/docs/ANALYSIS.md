**مشکلات شناسایی‌شده که در نسخه‌ی جدید برطرف می‌شوند:**
1. `localStorage` — سقف ~۵ MB، مختص یک مرورگر، بدون اشتراک شبکه‌ای.
2. رشته‌های comma-separated برای چندانتخابی‌ها → گزارش‌گیری دقیق ناممکن.
3. `ALL_WELLS` hardcoded.
4. تزریق HTML در `onclick="selectWell('${w}')"` و در سلول‌های جدول (XSS محلی).
5. بدون صفحه‌بندی → کندی روی داده‌ی بزرگ.
6. حذف فیزیکی بدون سابقه.
7. تاریخ‌ها متن آزاد، بدون تقویم.
8. «پاک کردن همه» بدون پشتیبان.
9. Import وجود ندارد.

### ۳٫۲ در HTML هست، در اکسل نیست → **حفظ می‌شود**

- گزینه‌های خرابی «اضافه آمپر / اضافه جریان / اتصال کوتاه / تعویض لوله آبده / اهم دار و افزایش دبی / تغییر فشار و دبی» — در دو سال اخیر استفاده نشده ولی **حذف نمی‌شوند**.

### ۳٫۳ تناقض‌های ساختاری و راه‌حل

| تناقض | راه‌حل |
|---|---|
| «تیپ پمپ قبلی» در اکسل `384/10` (تیپ+طبقه) ولی «تیپ پمپ فعلی» فقط تیپ | دو ستون مجزا `pump_prev_type` و `pump_prev_stages` + نگه‌داشتن رشته‌ی خام `pump_prev_raw`؛ Import آن را می‌شکند |
| فیلدهای radio در HTML، ولی داده‌ی واقعی مقادیر خارج از فهرست دارد (املاء/موارد نادر) | هر فیلد گزینه‌ای، گزینه‌های فعال را دکمه‌ای نشان می‌دهد **به‌علاوه‌ی ورودی «سایر»** — مقدار خارج از فهرست پذیرفته و ثبت می‌شود، پس Import هیچ داده‌ای را دور نمی‌ریزد |
| ۲۶ املای مختلف برای ~۱۰ پیمانکار | جدول `lookup_aliases`: هر گزینه می‌تواند چند «نام مستعار» داشته باشد؛ Import خودکار نرمال‌سازی می‌کند و گزارش‌ها تمیز می‌شوند |
| ۹۳۹ رشته‌ی نام چاه در برابر ۳۴۲ نام تمیز | جدول `wells` با ۳۴۲ نام کانونی + `well_aliases`؛ نام ناشناخته در Import به‌صورت «چاه تأییدنشده» ساخته می‌شود، نه دورریخته |

| «چاههای با عمر کمتر از یک سال» در اکسل گاهی برابر «تعداد ماه‌های کارکرد» است | هر دو ستون جدا نگه داشته می‌شوند، بدون استنتاج |

### ۳٫۴ مواردی که داده‌ی کافی برای آن‌ها نیست

طبق «قانون نهایی»، برای موارد زیر مقدار فرضی ساخته **نشده** و به‌جای آن ساختار قابل‌تنظیم طراحی شده است:
- منحنی کارکرد پمپ (شیت `رجائی 2`) فقط برای یک چاه موجود است → جدول `pump_curve_points` ساخته می‌شود ولی خالی می‌ماند؛ گزارش ۱۴ روی `دبی طراحی` در برابر `دبی آزمایش` کار می‌کند که برای همه‌ی رکوردها موجود است.
- «تعداد ترمیم / جنس جدار / قطر جدار» فقط ۲ نمونه دارند و آن هم آشفته است → به‌صورت فیلدهای اختیاری فرم‌ساز، بدون گزینه‌ی پیش‌فرض.
- کاربران/نقش‌ها: هیچ داده‌ای موجود نیست → جدول `users` و ستون `user_id` در `audit_logs` ساخته می‌شود ولی ورود اجباری نیست (آماده برای فعال‌سازی RBAC).
