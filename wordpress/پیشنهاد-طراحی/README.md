# پیشنهاد طراحی — صفحه‌ی اصلی

یک **پیشنهاد بصری** برای صفحه‌ی اصلی `saadatmehracademy.com`.
محتوا، ساختار منو و رنگ‌های برند همان‌اند؛ فقط زبانِ طراحی عوض شده.

> این پوشه روی سایت اجرا نمی‌شود. هیچ فایلی از قالب را تغییر نمی‌دهد.
> انتقالش به قالب یک تصمیم جداگانه است.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | نسخه‌ی قابل ویرایش. تصویرها و فونت‌ها را از `../themes/kadence-child/assets/` می‌خواند، پس چیزی دوباره در مخزن کپی نشده. |
| `../پیشنهاد-طراحی-سعادت‌مهر.html` | نسخه‌ی تک‌فایلی برای نشان دادن به کارفرما. همه چیز درونش است؛ هر جا باز شود کار می‌کند. |

## ساختِ دوباره‌ی نسخه‌ی تک‌فایلی

پس از هر ویرایشِ `index.html`:

```sh
python3 tools/inline-assets.py \
  "wordpress/پیشنهاد-طراحی/index.html" \
  "wordpress/پیشنهاد-طراحی-سعادت‌مهر.html"
```

## آنچه در این نسخه فرق می‌کند

هشت بخش، هشت چیدمانِ متفاوت — به جای تکرارِ «تیتر وسط + سه کارت»:

1. هیروی نامتقارن، عکس و متن ۵۰/۵۰
2. نوار اعتبار علمی، بلافاصله زیر هیرو
3. مانیفست تایپوگرافیک، بدون کارت
4. ریلِ افقیِ پروتکل ۱۰۰ روزه
5. آمارِ یک پرونده، کنار عکسِ عمودی
6. کلاژِ پلکانیِ مطبوعات روی زمینه‌ی سرمه‌ای
7. معرفی کتاب، دو ستونی
8. فراخوانِ پایانی، متمرکز

## نکته‌های فنی

- CSS بومی، بدون بیلد و بدون کتابخانه — چون مقصد یک قالب فرزندِ دست‌نویس است.
- انیمیشن‌ها با `IntersectionObserver` و `animation-timeline: view()`؛ هیچ شنونده‌ی `scroll` نیست.
- `prefers-reduced-motion` و حالت تاریک هر دو پوشش داده شده‌اند.
- همه‌ی عکس‌ها واقعی‌اند؛ هیچ تصویرِ ساختگی یا placeholder ندارد.
