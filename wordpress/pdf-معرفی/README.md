# سندِ معرفی — «معماری متابولیک»

منبعِ ساختِ فایل `wordpress/معماری-متابولیک-معرفی.docx`.

## فونت‌ها

| | فونت | چطور ثبت شده |
|---|---|---|
| فارسی  | **B Nazanin**      | `w:cs` + `w:szCs` + `w:bCs` روی هر ران |
| لاتین  | **Times New Roman** | `w:ascii` و `w:hAnsi` روی هر ران |

هر دو فقط با **نام** در فایل ثبت شده‌اند، نه جاسازی‌شده. ورد روی ویندوز
خودش آن‌ها را برمی‌دارد. اگر روی دستگاهی B Nazanin نصب نباشد، ورد فونتِ
دیگری می‌گذارد و ظاهر عوض می‌شود.

## ساختِ دوباره

```sh
python3 wordpress/pdf-معرفی/build.py "wordpress/معماری-متابولیک-معرفی.docx"
```

## چرا rtl.py جداست

ورد برای فارسی سه چیزِ جدا می‌خواهد و اگر یکی جا بیفتد سند بی‌صدا خراب
می‌شود:

* `<w:bidi/>` در `pPr` — جهتِ پاراگراف
* `<w:rtl/>` در `rPr` — جهتِ ران
* `w:cs` و `w:szCs` — فونت و اندازه‌ی «خطِ پیچیده»

`w:sz` فقط اندازه‌ی لاتین را عوض می‌کند؛ اندازه‌ی فارسی از `w:szCs`
می‌آید. درشتی هم `w:bCs` می‌خواهد نه فقط `w:b`.

همچنین ترتیبِ فرزندانِ `pPr`، `rPr`، `tcPr`، `tblPr` و `sectPr` در
OOXML اجباری است؛ اگر عنصری سرِ جایش نباشد ورد فایل را اصلاً باز
نمی‌کند. به همین دلیل هیچ‌چیز `append` نمی‌شود و همه با
`insert_ordered` سرِ جای درست می‌نشیند.

## نکته‌ی عرضِ جدول

تنظیمِ `cell.width` به‌تنهایی کار نمی‌کند. تا `tblLayout` روی `fixed`
نباشد و `tblGrid` پر نشود، ورد خودش ستون‌ها را جا می‌دهد. `fix_table()`
هر سه را با هم می‌گذارد.
